📱 WaterOps App Updates

Stay current with the latest releases, features, and improvements to the WaterOps water operations management app.

Feature New July 2026 v2.4

Command Center Overhaul & Admin Security

This release brings a significant upgrade to the Water Command Center interface, a hardened admin authentication system, and several reliability improvements based on operator feedback.

  • Rebuilt Water Command Center dashboard with improved layout and faster data rendering for large water systems.
  • New admin authentication: admin code is now securely version-controlled to prevent stale credentials on device upgrades or app reinstalls.
  • Admin code migration automatically resets to the correct credential on first launch — eliminating "wrong code" issues after updates.
  • Improved navigation flow between Water Command Center sections for faster operator workflows.
  • Performance improvements across all dashboard views, especially on older iPhone hardware.
  • Fixed: iPhone physical devices now correctly sync admin credentials that were previously only working in the iOS Simulator.
⚠️ Update note: If you previously had trouble with your admin code on a physical iPhone, this update resolves the issue. After updating, launch the app once and your credentials will be automatically migrated. No manual action needed.
Improvement Fix May 2026 v2.3

Reporting Enhancements & Bug Fixes

A focused update addressing reporting accuracy, offline handling, and several bugs reported by water operators in the field.

  • Updated daily water usage report format to match state reporting requirements for small public water systems.
  • Improved offline mode — the app now caches the last 7 days of data for access without an internet connection.
  • Fixed issue where pump run-time totals could show incorrect values after midnight rollover.
  • Fixed: Chemical dosage entry fields now correctly save values entered in mg/L without rounding errors.
  • Improved accuracy of flow rate calculations for systems using variable-speed pump drives (VFDs).
  • Added confirmation dialog before clearing any operational log entries to prevent accidental data loss.
  • Minor UI adjustments to comply with iOS 17 display guidelines.
Feature March 2026 v2.2

Chemical Treatment Log & Alert System

Introducing a dedicated chemical treatment log and a configurable alert system for water quality parameters — making compliance documentation faster and more reliable.

  • New Chemical Treatment Log: record daily chlorine residual, pH, turbidity, and other parameters with timestamps and operator signatures.
  • Configurable parameter alerts — set thresholds for any water quality value and receive in-app notifications when readings go out of range.
  • Chemical treatment records now auto-generate a monthly summary report in PDF-ready format.
  • Added chlorine decay calculator tool to help operators estimate residuals at distant points in the distribution system.
  • Turbidity trending graph now shows a 30-day rolling view for source water monitoring.
  • Improved data export: all logs can now be exported as CSV for use in spreadsheets or state reporting portals.
Improvement Fix January 2026 v2.1

iPad Layout & Stability Update

Improved layouts for iPad users and addressed several stability issues identified after the v2.0 launch.

  • Full iPad layout optimization — all screens now properly adapt to iPad screen sizes in both portrait and landscape orientations.
  • Split-view support on iPad for viewing the dashboard while entering log entries side-by-side.
  • Fixed crash that could occur when switching between multiple water systems with different configurations.
  • Fixed: date picker in log entry screens now correctly handles month boundaries.
  • Reduced app launch time by approximately 30% through optimized data loading.
  • Improved VoiceOver accessibility labels across all main screens for operators using assistive technology.
Major Release November 2025 v2.0

WaterOps 2.0 — Complete Rebuild

Version 2.0 is a complete rebuild of WaterOps from the ground up, designed for modern iOS and optimized for the unique needs of small and medium public water systems.

  • All-new native iOS interface built with modern Swift and WKWebView for a fast, responsive experience.
  • Water Command Center: a unified dashboard showing system status, pump run times, water levels, and recent alarms at a glance.
  • Multi-well and multi-pump support — manage complex water systems with multiple sources and distribution zones.
  • Operator log redesigned with voice-to-text support for faster field data entry.
  • Built-in reference library with common formulas: flow calculations, dosage math, pump efficiency, and more.
  • Secure admin area with configurable system settings, protected by a PIN-based authentication system.
  • Dark mode support throughout the entire app.
  • iCloud sync for automatic backup of all log data across devices.
🎉 Welcome to WaterOps 2.0. If you're upgrading from version 1.x, your historical log data will be automatically imported on first launch. The import process may take a minute or two depending on your data history.
Archive 2024 – 2025 v1.x

WaterOps 1.x — Original Series

The original WaterOps app established the core workflow for daily water system operations logging. Version 1.x was the foundation that shaped everything in v2.0.

  • v1.5: Added pump hour meter tracking and basic maintenance reminder system.
  • v1.4: Introduced daily operator log with supervisor review capability.
  • v1.3: Added water meter reading input and monthly usage calculation.
  • v1.2: Bug fixes and improved stability for older iPhone models.
  • v1.1: Added support for multiple chemical treatment types in daily log.
  • v1.0: Initial release — basic daily log, pump status tracking, and contact list.
